# Хор (khor) — контекст проекта

Чат, где отвечает не ассистент, а внутренний хор голосов в духе Disco Elysium.
Обычно говорит один голос; два-три — если тема тянет в стороны; весь хор — редкое
событие. Каст собирается под конкретного пользователя во вступительном разговоре.

## Архитектура

- `src/` — фронт: Vite + React + TS. Тёмный фон, янтарный текст, CRT-эстетика.
  Логика в `src/hooks/useChorus.ts`, App — вьюха. Состояние в IndexedDB (`src/lib/db.ts`),
  сервер stateless — весь `UserState` уходит в каждом запросе.
- `worker/` — бэкенд: Cloudflare Worker (`src/index.ts`) + Node-хост для VPS
  (`src/node-server.ts`, `npm start`, переиспользует тот же fetch-обработчик).
  Эндпоинт: `POST /respond`.
- `shared/` — общий код фронта и воркера: типы, ростер голосов, архетипы, онбординг.

## Ключевые решения (не менять без запроса пользователя)

1. **Две роли модели** через форс tool_choice: исполнитель (голоса, в характере,
   sonnet-4-6 / opus-4-8 для режима deep) и кастинг-директор (анализ, вне характера,
   sonnet-4-6). Zod-валидация, один ретрай, диегетический фолбэк.
2. **Каст = 8 архетипических слотов Джона Биби** (`shared/archetypes.ts`):
   Герой/Родитель/Ребёнок/Душа (свет) + Оппонент/Критик/Трикстер/Демон (тень).
   Слот — отношение голоса к пользователю; какой из 25 голосов (`shared/voices.ts`)
   занимает слот — подбирает директор. Фиксированного «ядра» нет.
3. **Слот Героя сменный**, по умолчанию Ритор (хост). Роль голоса пользователю
   НЕ показывается — только слышна в манере (решение пользователя: «неявно»).
4. **Онбординг**: хор собирается на глазах из одного Ритора. Первый ход фиксирован —
   вопрос «заточенная палка» с чипами (`shared/onboarding.ts`); скрытый `reveals`
   выбранного чипа уходит директору. Мягкий потолок ~6 ходов, потом добор слотов.
5. **Стиль реплик — требование пользователя**: легко и просто, никакой подростковой
   драмы, пафоса, дешёвой образности, терапевт-спика («раны», «травмы», «сломал» —
   запрещено). Сухой ум лучше надрыва. Гард вшит в оба системных промпта — сохранять.
6. **Окно контекста**: исполнитель видит 24 хода, директор 30; полная история — у
   клиента, старший контекст живёт в profile. В live директор и исполнитель идут
   параллельно, в онбординге — последовательно (сцене нужен вводимый голос).
7. **Лицензия проприетарная** (all rights reserved). Проект вырос из форка
   tldraw/draw-fast, но кода tldraw не осталось.

## Команды

- Фронт: `npm run dev` (Vite, проксирует /respond на :8787), `npm run build`, `npx tsc --noEmit`
- Воркер: `npm --prefix worker run dev` (wrangler), `npm --prefix worker run typecheck`,
  `npm --prefix worker start` (Node-хост, нужен env `ANTHROPIC_API_KEY`)
- Формат: `npm run format` (prettier, табы, без точек с запятой)
- Деплой на VPS: см. `DEPLOY.md` (systemd + Caddy/nginx, /opt/khor)

## Пользователь

- Windows + PowerShell: команды для его машины давай в PowerShell-синтаксисе,
  по одной на строку, без `&&` и `\`-переносов.
- Прямой, ценит краткость, не выносит кринж и пафос в текстах продукта.

## Очередь идей (обсуждались, не реализованы)

- RPG-слой: теневые голоса открываются постепенно, по мере доверия.
- Пул вступительных вопросов (3–4, случайный) вместо одного фиксированного.
- Стриминг ответов; D1 для мультиустройства; TTS.
- Настоящие портреты (Midjourney: ризограф-гротеск, единая «проявка» — моно-янтарь,
  халфтон, скан-линии; `--sref` общий). Сейчас — процедурные плейсхолдеры.
- Конструктор каста вручную.
