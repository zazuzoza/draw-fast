# Хор / chorus

Чат-оболочка, где на сообщение отвечает **не один ассистент, а внутренний хор
голосов** в духе Disco Elysium. Обычно говорит один голос — тот, кто ближе к
ситуации; иногда два-три; полный хор — редкий сюжетный пик. Каст не фиксирован:
он собирается под конкретного пользователя через честный вступительный разговор.

Тёмный фон, бледно-янтарные буквы, портрет говорящего сбоку.

## Стек

- **Бэкенд:** Cloudflare Worker, эндпоинт `POST /respond` (`worker/`).
- **Фронт:** Vite + React + TypeScript → Cloudflare Pages (`src/`).
- **LLM:** Anthropic API через tool-use.
  - **Исполнитель** (голоса, в характере): `claude-sonnet-4-6`, либо
    `claude-opus-4-8` в режиме «глубже».
  - **Кастинг-директор** (анализ, вне характера): `claude-sonnet-4-6`.
- **Память:** IndexedDB на клиенте (MVP). Сервер без состояния — весь `UserState`
  уходит в каждом запросе.
- **Общий код:** `shared/` — типы и ростер голосов, импортируются и фронтом, и воркером.

## Две роли модели

| | Исполнитель | Кастинг-директор |
|---|---|---|
| Голос | в характере, играет | вне характера, молчит для пользователя |
| Выход | сцена из реплик (`speak`) | обновление `profile` / `activeCast` (`cast_update`) |
| Когда | каждый ход | плотно в онбординге, изредка в live |

Каждый вызов форсит `tool_choice`, валидируется через zod, при провале — один
ретрай → фолбэк (одна реплика).

## Каст

Голос — точка в трёх осях: **функция × линза × регистр** (см. `shared/voices.ts`).

- **Ядро (7, всегда в касте):** Ритор (хост), Бритва, Сердце, Скептик, Драйв,
  Архивариус, Оракул.
- **Ростер (18, добирается под пользователя):** Таран, Затейник, Свидетель,
  Подстрекатель, Сторож, Мифологизатор, Циник, Утешитель, Делец, Совесть, Тело,
  Стратег, Саботажник, Дитя, Игрок, Романтик, Дипломат, Бунтарь.

Онбординг начинает один голос — **Ритор** — с калиброванного крючка, и по мере
понимания «распадается» на хор: кастинг-директор добирает голоса под стиль
человека, доводя активный набор до ~7. Затем `phase: live`.

## Запуск локально

Нужен ключ Anthropic API.

```bash
# 1. Зависимости
npm install
npm --prefix worker install

# 2. Секрет воркера для локалки
cp worker/.dev.vars.example worker/.dev.vars
#   и впиши ANTHROPIC_API_KEY=...

# 3. В одном терминале — воркер (порт 8787)
npm run worker:dev

# 4. В другом — фронт (Vite проксирует /respond на воркер)
npm run dev
```

Открой адрес, который напечатает Vite.

## Деплой

- **Воркер:** `wrangler secret put ANTHROPIC_API_KEY`, затем `npm run worker:deploy`.
- **Фронт (Cloudflare Pages):** билд-команда `npm run build`, каталог `dist`.
  Задай `VITE_API_BASE` = адрес задеплоенного воркера.

## Контракт API

`POST /respond`

```json
{ "userState": { "phase": "...", "profile": {}, "activeCast": [], "history": [] },
  "message": "...", "mode": "default" }
```

Ответ:

```json
{ "userState": { "...обновлённое" },
  "scene": [ { "voice": "razor", "line": "...", "intensity": "normal" } ] }
```

`intensity`: `whisper | normal | shout` → размер портрета и типографики.
